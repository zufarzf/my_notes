#####  #####  #####  #####  nohup  #####  #####  #####  #####  #####  #####  #####  #####  #####
  
nohup - сокращение от слова no hang up (не вешай трубку).
Без но nohup приложение умирает с сессией.


#####  #####  #####  #####  Path to Java interpreter  #####  #####  #####  #####  #####  #####  #####

потом указывается путь до нужного интерпритатора java.
path/to/java/interpreter

  
#####  #####  #####  #####  -Xmx  #####  #####  #####  #####  #####  #####  #####  #####  #####  #####

-Xmx<size:int>M (пример: -Xmx1024M) - это параметр JVM.
Xmx - это maximum heap size, то есть максимальный размер памяти которую java может использовать для кучи (heap).
  -Xmx1024M hfphtibnm Java использовать до 1024 мегабайта памяти.

heap - это область памяти, где Java (и не только) хранит объекты во время работы программы.

Если памяти мало:
  * приложение может тормозить.
  * может упасть с OutOfMemoryError.

Если памяти слишком много задать без приины:
  * можно зря занять память сервера.
  * приложение может не стартовать, если сервер не может выделить столько.


#####  #####  #####  #####  -jar  #####  #####  #####  #####  #####  #####  #####  #####  #####  #####

-jar этот ключ говорит java: "Запусти не просто класс, а jar-файл как готовое приложение"
То есть после -jar Java ожидает путь к file.jar

Примерно так:
  * без -jar мы бы запускали какой-то класс через classpath.
  * с -jar мы запускаем готовый упакованный Java-архив как приложение.


#####  #####  #####  #####  /path/to/app/jar/file.jar  #####  #####  #####  #####  #####  #####  #####

/path/to/app/jar/file.jar - это путь к самому jar-файлу приложения.
мы говорим запусти приложение, которое лежит в этом jar.


#####  #####  #####  #####  /path/to/nohup.out  #####  #####  #####  #####  #####  #####  #####

/path/to/nohup.out - это перенаправление стандартного вывода.
символ > означает: записать stdout в файл.

stdout - это обычный вывод программы:
  * System.out.printls()
  * обычные сообщения
  * стартовые логи
  * информационные сообщения

То есть: /home/suport/ssc/nohup.out
  значит:
    всё, что программа пишет в стандартный вывод, записывать в файл nohup.out

* Если файла нет - создаётся.
* Если файл есть - он будет перезаписан.
* Если вместо > поставить >>, тогда данные дописывались бы в конец.

  
#####  #####  #####  #####  2>&1  #####  #####  #####  #####  #####  #####  #####

Это чуть хитрее, но очень важная часть.
 
Что такое 2?
В Linux у процесса есть стандартные потоки:
  * 0 - stdin (ввод)
  * 1 - stdout (обычный вывод)
  * 2 - stderr (ошбки)

То есть:
  * 1 = Обычные сообщения
  * 2 = Ошибки

Что делает 2>&1?
Это значит:
  перенаправь stderr туда же, куда сейчас направлен stdout

Разберём:
  * 1 - stdout
  * 2> - перенаправить stderr туда же, куда сейчас направлен stdout

То есть сначала в команде stdout идёт в файл  /home/suport/ssc/nohup.out,
а потом 2>&1 говорит и ошибки тоже отправляй в тот же самыЙ файл. 


#####  #####  #####  #####  &  #####  #####  #####  #####  #####  #####  #####

Амперсант в конце означает:
  Запусти процесс в фоне.

То есть терминал не будет занят этим приложением.
